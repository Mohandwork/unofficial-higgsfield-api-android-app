# Higgsfield Android App

A starter Android app built with Kotlin and Jetpack Compose.

## Open and run

1. Open this folder in Android Studio.
2. Allow Android Studio to sync the Gradle project and install any suggested SDK components.
3. Select an emulator or connected Android device.
4. Press **Run**.

The project uses package name `com.higgsfield.mobile` and requires Android SDK 35 for compiling, with Android 7.0 (API 24) as the minimum supported version.

## Publish to GitHub

Create an empty repository on GitHub, then run these commands from this folder:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git branch -M main
git push -u origin main
```

The repository is already initialized locally and the initial project files are committed.
